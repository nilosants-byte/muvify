# Lotes de Execucao E2E

Arquivo de configuracao:
- `implemented-flows-by-priority.json`

Formato:
- `high`: lista de flows yaml implementados de alta criticidade
- `medium`: lista de flows yaml implementados de media criticidade
- `low`: lista de flows yaml implementados de baixa criticidade

Comandos:
- `npm run e2e:mobile:batch:high`
- `npm run e2e:mobile:batch:medium`
- `npm run e2e:mobile:batch:low`

Com relatorio/evidencias:
- `npm run e2e:mobile:batch:high:report`
- `npm run e2e:mobile:batch:medium:report`
- `npm run e2e:mobile:batch:low:report`
