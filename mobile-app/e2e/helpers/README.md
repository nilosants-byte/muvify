# Helpers E2E

Arquivos de apoio para execucao E2E.

- `run-maestro.mjs`: runner padrao para executar modulos Maestro com/sem modo report.

Convencoes adotadas:

- IDs estaveis de tela: `screen.<dominio>.<tela>`
- IDs estaveis de botoes: `button.<dominio>.<acao>`
- IDs estaveis de inputs: `input.<dominio>.<campo>`
- IDs da bottom nav: `nav.bottom.<key>`
